# iPhone 16 Pro Max 效率补丁 v4：安装、测试与回退

版本：0.4.0 / build 5，iphone16-efficiency-v4。这是供你自行签名和实机测试的候选版。已完成组件回归、iOS 编译和包校验；未自动安装、启动手机游戏或测量这一版游戏帧率。不能据此承诺持续稳定 30 FPS、原生内部 720p 或 HDR 已正常。

## 选择一种安装方式

直接使用 Cyberpunk2077-iPhone16ProMax-efficiency-v4-candidate.ipa 最方便。用原来的 iLoader、同一个 Apple ID 和同一个签名后应用 ID 覆盖更新，重新签名主应用及嵌套库。保留原应用，手机上的正版资源和存档无需重传。安装前退出游戏并保存进度。

若要使用补丁，解压 Cyberpunk2077-iPhone16ProMax-efficiency-v4-patch.zip，把补丁文件夹放在原 v3.1 IPA 或 performance-capture IPA 旁边，双击文件夹里的“生成优化版IPA.command”。它会校验原包 SHA-256，生成 efficiency-v4-patched.ipa，再检查全部文件；不会签名、安装或改手机数据。必须使用此前交付的原始未重新签名 IPA；重新签名过的包不匹配补丁。生成的 IPA 再按上一段签名覆盖安装。

补丁包含自建宿主和兼容层的替换文件、配置、源码差异和适用版本清单。商业游戏可执行文件如有差异，仅包含字节范围补丁；不包含整个游戏可执行文件或 96 GB 游戏资源。原始 IPA 保留以便回退。

## 本次改动

- 窗口布局请求改为合并后交给 UIKit 主线程，渲染线程不再每帧同步等待布局。窗口创建、位置/大小设置仍按原有同步语义执行；渲染线程必要的 Core Animation flush 保留。
- 显示尺寸、缩放和刷新率读取使用由 UIKit 更新的原生屏幕快照，减少渲染线程反复同步查询。布局、屏幕模式和前后台切换会更新快照；物理刷新率和 GPU 能力不被改写。
- 资源路径 UTF-8 字符串使用每线程四项小缓存，减少反复转换的分配开销。文件存在性、写入覆盖、当前目录、权限、大小写回退均保持实时读取，资源/存档数据不做额外复制或缓存。
- 常规 Metal 提交减少兼容层附加的完成回调；呈现命令和第一项提交仍观察错误。完整命令错误观察与 GPU 时间戳可通过诊断启动启用，游戏自己的回调和所有命令仍原样执行。运行报告明确标注观察范围，不能把普通模式的零错误数当作所有上传命令无错误的证明。
- 日志队列降至 utility 优先级，减小与前台游戏任务的争用；不改变游戏工作线程数量、锁、AI 或物理更新。
- 撤回 v3 的 5 秒资源过期覆盖，使用原始 rendering.ini 和引擎自身的资源保留策略，避免未经流送验证的提前释放反复触发解压/上传。内存占用和流送收益尚未实机测得。
- 停止首次启动时强制低画质、人群密度、LOD 或关闭画面效果。v4 首次策略只设全屏短边 720 的输出画布、30 FPS 上限与动态分辨率的 30 FPS 目标；其余选项，包括 HDR、帧生成、升频器和手柄设置，保持你当前的选择。v3 已写入的低画质不会自动恢复，你可自行调整；相关备份保留。
- 保留 v3.1 的浮点配置修正，以及已有五条分配器容量/初始提交常量修改。128 MiB 初始提交保留按需增长；没有新增游戏 AI、任务、NPC、地图、碰撞、物理或渲染功能指令补丁。

原生 Metal 管线的补充持久缓存曾进行实验，热缓存反射信息检查未通过，已从交付代码排除。游戏及 Metal 自带的缓存继续使用。没有使用 JIT、CPU 模拟、串流、Windows DLL 模组或伪造硬件能力。

## 实机测试

1. 更新后先确认能启动、载入原存档，打开地图，再保存一次并重载。若闪退，保留最新系统崩溃报告，不要反复卸载重装。
2. 在相同存档、相同画质和相同环境下，用手柄测试同一条跑图路线和同一场战斗，先观察 2–3 分钟，再连续玩至少 20 分钟观察发热后的掉帧。测试时保持充电方式、亮度和游戏模式一致。
3. 为比较真实渲染帧率，首轮可在游戏内关闭帧生成。不要只报峰值；请记录大致平均帧率、明显停顿、战斗响应和持续运行后是否变差。
4. v4 保留你的动态分辨率设置。720 是输出画布短边；若仍使用原来的 40–50% 动态渲染，内部短边约 288–360，再升频到输出画布。若要求真正内部 720p，应在游戏里选择 100% 或关闭动态升频，再单独比较帧率。这里没有把低内部渲染标为原生 720p。
5. HDR 保留为可选设置，但现有移植尚未完成真正 HDR 输出验证。如果开启后画面异常，记录现象；不能把系统 EDR 能力或游戏内可选择 HDR 当作 HDR 已正常。

普通图标启动不启用详细性能采样。排错可导出应用 Documents/probe-report.json、runtime.log，以及 PerformanceOverrides/iphone16-efficiency-v4/profile-report.json。若闪退另附系统“分析数据”中对应 CyberpunkRebuilt 的最新 .ips。无需提供 Apple ID 密码。

## 回退

保留此前可以游玩的 Cyberpunk2077-iPhone16ProMax-performance-capture.ipa，使用同一账号和签名后 ID 覆盖安装即可回退代码。原 v3（0.3.0/build 3）已有三次浮点配置断言闪退，不应回退到它。v3.1 的启动恢复也尚未获得实机确认。

v4 首次改设置前完整备份为应用数据容器 Library/Application Support/CD Projekt Red/Cyberpunk 2077/UserSettings-before-iphone16-efficiency-v4.json。回退 IPA 不自动恢复设置；需要恢复时，退出游戏后用该备份恢复 UserSettings.json，保留 JSON 中浮点字段的小数/指数写法。不要删除 GuestGame、GuestWritable、saves 或应用数据容器。

适用游戏固定为 Steam macOS ARM64 2.31，App 2.3.1/build 5314028，UUID A6656ADC-FBE2-36A4-9B9D-B4A9DE645089。本轮优先 iPhone 16 Pro Max；iPhone 13 Pro 的 BC 纹理兼容和持续 30 FPS 不在本轮已验证范围。

详细证据：源码包 evidence/performance-v4-components.json、performance-v4-rejected-archive.json、performance-v3.1-startup-fix.json，以及 IPA/补丁同名 verification.json。组件检查和包检查不会替代游戏实机测试。
