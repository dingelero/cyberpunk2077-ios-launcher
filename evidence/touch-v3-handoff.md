# 触控新版 v3：安装与键位编辑

版本：0.6.0 / build 8。完整包为 `Cyberpunk2077-iPhone16ProMax-touch-v3-candidate.ipa`。本轮交付触控重做；用户要求直接打包并自行进行实机测试。

## 安装

用现有 Apple ID 和 iLoader 重签完整 IPA，包含主应用与嵌套动态库。沿用当前已安装应用 ID `local.cyberpunk.ios.rebuilt.<your-signing-suffix>`，覆盖更新。不要卸载旧应用，否则应用里的正版资源和存档可能被删除。若签名工具改变 ID，请先恢复原 ID 再安装。本包不包含约 96 GB 游戏资源，现有导入数据继续使用。

## 操作

- 左半屏空白区域按下：摇杆在触点生成，拖动控制移动，松手立即隐藏；默认没有固定移动摇杆。
- 右半屏空白区域滑动：按每次位移转动视角，手指停住或松开不持续转动；抬起后可在另一位置继续滑动，不显示右摇杆。
- 手指的操作从按下到松手独立保持，跨越屏幕中线不会切换操作。移动、转视角、LT 瞄准和 RT 射击设计为可同时使用。第二根在同一移动/视角区域按下的手指不会抢走已有操作。
- 按钮采用黄/青色切角样式，按键覆盖 ABXY、LT/RT、LB/RB、L3/R3、方向键和菜单。另有地图、物品、日志快捷键；VIEW 默认隐藏，可在编辑时启用。
- 按钮超过 4 秒没有屏幕触摸自动隐藏；仍有手指按住时保持显示。隐藏后第一次触摸唤醒按钮，并按空白区域操作，不会盲按到看不见的射击键。
- 接入实体手柄时由实体手柄优先，触控镜头/移动区域让出。进入键位编辑、切到后台或离开游戏时释放触控按键和移动状态。

顶部模式按钮循环切换「自动 → 游玩 → 界面」。自动依据原游戏的光标捕获状态切换。若载入存档后空白区域没有移动/转视角，切到「游玩」；主菜单或地图需要直接点选/拖动时切到「界面」。界面模式的空白触摸传给原游戏菜单。菜单按钮若与自定义游戏键位不匹配，可在布局编辑里改成「返回 / Esc」或「继续 / 回车」。

## 自定义

先暂停游戏，点顶部「布局」。点选或拖动任意按钮，调整位置、大小、透明度、是否显示和功能绑定。可选完整手柄按钮，以及地图、物品、日志、回车、电话、呼叫载具、Esc、快速存档，共 24 种绑定。按钮的中文标题按默认游戏手柄预设描述；实际行为仍由游戏的控制设置决定。

「镜头 / 摇杆」页可调普通镜头灵敏度、瞄准灵敏度倍率、摇杆半径与纵向反转。面板标题可拖动；点「收起」可编辑被面板挡住的键，顶部「参数」再次展开。点「保存完成」或顶部「完成」保存，点「取消」恢复编辑前状态，点「全部默认」恢复默认布局后仍需保存。

布局保存到应用的 `Library/Application Support/CP2077Touch/layout-v3.json`，独立于游戏画质和存档。两个系统入口「模式」「布局」不能被隐藏或改成游戏按钮，避免无法再次进入设置。

## 验证范围

已完成 iOS ARM64 构建、依赖检查和 IPA 签名/包校验。生产输入模型在 ARM64 Mac 上通过四路接触角色、额外手指不抢占、静止视角零位移、滑动采样数不改变总位移、四种屏幕尺寸默认键位不重叠、非法配置回退和 JSON 保存重读检查。

非商业游戏的模拟器组件探针确认：原生软件手柄的 12 个按钮、方向键、移动轴能收到各元素的原生回调；L3/R3/Menu/VIEW 存在；移动、瞄准和射击状态可并存；相邻镜头事件合并保持总位移，且不跨越按钮/键盘事件。模拟器触摸记录观察到左摇杆随不同初始触点生成、松手隐藏，编辑面板可打开。实际拖动检查发现 UIKit 可能返回空的合并采样列表，已添加当前触点回退并重新构建。

未验证：真机四指并发、此软件手柄在商业游戏里的完整响应、实机镜头方向与灵敏度、菜单自动切换、编辑界面操作后保存并重启。用户要求直接打包，未继续交互测试；组件检查不等于完整游戏实测。

本轮继续使用 `iphone16-mobile-v2` 的画质迁移标记，已有设备不会重新强制迁移画质。游戏本体、资源、任务/NPC/物理内容、HDR 接口与存档路径未因这次触控更新改变。连续 30 分钟稳定 720p 输出 / 30 FPS 与 HDR 输出仍未验证，不能据本次打包宣布达标。
