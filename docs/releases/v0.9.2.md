# Cyberpunk2077 on iOS

**0.9.2 / build 20 · 540p 启动修复 v8**

免费、非官方的 Cyberpunk 2077 移动端启动器。需要自行准备正版 **Cyberpunk 2077 Steam macOS 2.31 ARM64** 游戏文件；IPA 不包含约 70–96 GB 的大型资源，也不会下载游戏本体。

### 系统与机型：请先阅读

- **已有游玩测试记录仅覆盖 iPhone 16 Pro Max / iOS 27。**
- **其他 iOS / iPadOS 版本、其他 iPhone 与 iPad 的兼容性尚不清楚。**自动识别设备、有对应预设或能安装，不代表游戏已确认可运行。
- IPA 的最低安装声明为 18.0；实际游玩测试范围仅为 iOS 27。
- 本次 v8 IPA 已完成构建、配置迁移和模拟器组件检查，尚未完成完整真机游玩验收。持续帧率、发热、HDR 及各机型可玩性需要进一步测试；不承诺稳定 30 FPS 或固定画质表现。

### 这一版包含什么

- 针对 v7 的分辨率初始化问题加入修复，恢复原生动态分辨率结构，并迁移已有配置。
- 提供 **540p / 720p / 1080p** 输出高度，按设备屏幕比例计算全屏宽度；默认自动识别设备，也可手动选择预设。
- 本地 ARM64 / Metal 渲染路径，不使用 JIT、CPU 模拟或串流。MetalFX 开启时，内部渲染分辨率低于输出分辨率。
- 中文 / English 启动器与触控界面、实体手柄输入、多点触控、浮动左摇杆、右半屏滑动视角、自定义键位与约 4 秒无触摸隐藏按键。

本次发布的就是附件 **540p 启动修复 v8**；未合并另外制作的 v7 低配补丁或后续 A15/13 Pro 实验改动。

### 下载与安装

1. 在下方 Assets 下载 **`Cyberpunk2077-DingElero-540p-startup-fix-v8.ipa`**，使用自己的有效签名方式安装；主应用及所有内嵌动态库都需要重签。
2. 更新时保持原来实际安装的 Bundle ID，**不要先卸载**，以保留已有资源、存档和自定义键位。签名工具添加过 ID 后缀时，沿用同一后缀。
3. 第一次打开启动器，创建 `GuestGame` 文件夹。已有完整资源的设备覆盖更新后无需重传。

### 只有手机：游戏文件这样放

完整下载并解压自己的匹配版本游戏文件，将 **`archive`、`engine`、`r6`、`Cyberpunk2077.app`** 四项直接移动或复制到：

**文件 → 浏览 → 我的 iPhone / iPad → 赛博朋克2077 → GuestGame**

签名工具修改了应用名称时，以实际名称为准。保留所有子目录，等待复制完成后再启动；不要多套一层 `Cyberpunk 2077`，也不要只放 ZIP、7z 或其他压缩包。

```text
GuestGame/
├─ archive/Mac/…
├─ engine/…
├─ r6/cache/tweakdb.bin
└─ Cyberpunk2077.app/Contents/…
```

本体资源约 **70 GB**，全部资源约 **96 GB**，另留解压、存档和运行空间。Windows 版或 Mac App Store 版文件不能直接替代本次要求的 Steam macOS 版本。手机可以通过自己的备份或外接存储完成导入，不需要使用电脑访问应用系统目录。

从 720p 开始测试，需要时选择 540p。详细步骤见下方 **`Cyberpunk2077-on-iOS-Guide-zh-en.md`**，或[在线教程](https://github.com/dingelero/cyberpunk2077-ios-launcher/blob/main/docs/DingElero启动器-使用教程.md)。

### English

**Cyberpunk2077 on iOS** is a free, unofficial launcher. This release is **0.9.2 / build 20, 540p startup fix v8**. Supply your own legitimate **Cyberpunk 2077 Steam macOS 2.31 ARM64** game files; large resources are not included or downloaded.

Gameplay testing has only covered **iPhone 16 Pro Max on iOS 27**. Other OS versions and devices have unconfirmed compatibility. This v8 IPA passed build, migration and simulator-component checks, but has not completed full physical-device gameplay acceptance. Sustained frame rate, thermals and HDR require device testing. Re-sign the IPA and all embedded libraries. Keep the same installed Bundle ID for updates and **do not uninstall first**. Preserve subfolders and wait for copying to finish. Allow about 70 GB for the base game or 96 GB for all resources, plus extraction and runtime space.

540p / 720p / 1080p denotes output height, with width based on screen aspect ratio. A preset does not guarantee compatibility or a fixed frame rate. See the bilingual guide in Assets for installation, controls and troubleshooting.
